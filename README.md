# Nina Carducci - Optimisation SEO et Accessibilité

## Description
Ce projet a été réalisé dans le cadre de la formation Intégrateur Web. Il s'agit de l'optimisation complète du site portfolio d'une photographe freelance. L'objectif principal était d'améliorer significativement les performances de chargement, l'accessibilité pour tous les utilisateurs, et le référencement naturel (SEO) du site existant afin d'atteindre les plus hauts standards de qualité web.

## Technologies et Outils Utilisés
* HTML5 Sémantique
* CSS3
* JavaScript
* Schema.org (Microdonnées SEO)
* Lighthouse (Audit de performance)
* WAVE (Audit d'accessibilité)

## Optimisations Réalisées
* **Performances** : Minification du code (HTML, CSS, JS), redimensionnement et compression des images (conversion vers des formats modernes comme WebP), et implémentation du chargement différé (lazy loading).
* **SEO** : Optimisation des balises méta, intégration du balisage sémantique enrichi (Schema.org) pour optimiser le référencement local, et correction de la hiérarchie des titres.
* **Accessibilité** : Ajout de descriptions alternatives (`alt`) pertinentes sur les images, vérification des ratios de contraste, et structuration sémantique du code HTML pour garantir une navigation fluide via les lecteurs d'écran.

## Installation et Consultation
Ce projet étant un site web statique classique, aucune installation de dépendances complexes (type npm) n'est requise.

1. Cloner ce repository en local :
`git clone https://github.com/Corentin25/Nina-Carducci.git`
2. Naviguer dans le dossier du projet :
`cd Nina-Carducci`
3. Ouvrir le fichier `index.html` directement dans votre navigateur web préféré pour visualiser le site. 

Note : Pour l'édition de code, il est recommandé d'utiliser une extension telle que "Live Server" sur Visual Studio Code pour bénéficier du rechargement automatique lors des modifications.
